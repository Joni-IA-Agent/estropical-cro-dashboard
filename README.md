# Estropical · Dashboard CRO

Dashboard de la propuesta de CRO para estropical.com.

- **Acceso:** privado, protegido por login.
- **Seguridad:** el contenido del dashboard está cifrado con **AES-256-GCM** (clave derivada por PBKDF2, 250 000 iteraciones). El HTML solo se descifra en el navegador tras introducir usuario y contraseña correctos. Sin las credenciales, el código fuente es ilegible.
- **Publicado con:** GitHub Pages.

Gestionado por uConvert Marketing.
